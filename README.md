### Descripción breve del proyecto
En esta primera entrega del Parcial 1 lo que hice fue hacer la pagina de Food Store con 2 HTML, uno para el Home y otro para el Carrito, ambos con sus estilos en CSS.
También tiene su logica para que todo funcione correctamente, se puede filtrar los productos y buscar productos.
En el carrito queda guardado lo que vayas agregando, por mas que refresques la pagina los productos no se eliminan sino que se quedan guardados en el localstorage.
Podes agregar, sacar o eliminar un producto desde el carrito o también podes vaciar todo el carrito e ir de nuevo al Home.


### Instrucciones para ejecutarlo
### 1. Instalar pnpm
Si no tenes pnpm instalado, podes hacerlo fácilmente a través de npm (que viene con Node.js) ejecutando el siguiente comando en tu terminal:
`npm install -g pnpm`

### 2. Instalar Dependencias del Proyecto
Una vez en la carpeta raíz del proyecto, instala las dependencias necesarias en la terminal con pnpm:
`pnpm install`

### 3. Ejecutar el Proyecto
Para iniciar el servidor de desarrollo de Vite, ejecuta en la terminal esto:
`pnpm dev`
La aplicación estará disponible en la URL que aparezca en la terminal (generalmente `http://localhost:5173`).
